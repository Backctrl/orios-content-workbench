# 内容创作工作台 · 使用指南

> 适用版本：@orios/dsh-creator v0.3.0（融合 creator-buddy 创作工作流）
> 配套：dsh-worktable（多窗口容器）、wewrite CLI（评分/查重/排版）、图像 Provider（图卡/配图）

---

## 1. 这是什么

面向 DeepSeek Harness 的内容连续生产工作台：**选题在前、主题在后，四级人工审批闸门**，一个主题从素材到可发布成品全程文件化、可追溯。

```
┌─────────────────────────────────────────────────────────────┐
│ dsh-worktable 多窗口（侧栏「工作台」→ ✍️ 内容创作工作台）      │
│  顶部栏 ── 总览与选题库 ── 内容编辑与修改 ── 配图及视频预览 ── 对话 │
└──────────────────────────┬──────────────────────────────────┘
                           │ /creator/api（本机 loopback）
┌──────────────────────────▼──────────────────────────────────┐
│ @orios/dsh-creator 插件                                       │
│  文件仓库（contentRoot）· 候选池 · 画像 · Provider · 评分/查重 · 图卡 │
└──────────────────────────┬──────────────────────────────────┘
                           │ 读写
┌──────────────────────────▼──────────────────────────────────┐
│ 内容库（文件即真相）                                            │
│  contentRoot/ _工作台/candidates.yaml · 2026-08/YYYY-MM-DD_slug/… │
└─────────────────────────────────────────────────────────────┘
```

## 2. 安装与配置

### 2.1 安装

```powershell
# 本地包安装
dsh plugin --profile web add .\orios-dsh-creator-0.3.0.tgz
# 或从 GitHub 获取源码后：dsh plugin --profile web add <仓库路径>
```

重启 `dsh web`（宿主加载服务端代码），浏览器刷新 → 侧栏「工作台」出现 **✍️ 内容创作工作台** 项目卡片，点击展开四窗布局。

### 2.2 profile 配置（cordis.patch.yml）

```yaml
- id: orios-creator
  config:
    mode: 'auto'
    contentRoot: 'F:/Ori-OS/内容创作'     # 内容库根目录（按月/主题组织）
    workbenchFolder: 'F:/Ori-OS'         # worktable 项目文件夹（缺省 $DSH_HOME/projects/orios-content-workbench）
```

- `contentRoot` 未配置 → mock 模式（可先验收界面）；配置后为文件真源。
- 插件首次激活会把 `ui/` 四窗页面 + `widget-result.json` 物化到 `workbenchFolder`（只写缺失文件，不覆盖你改过的页面）。
- 环境变量 `ORIOS_CREATOR_CONTENT_ROOT` 方式不可靠，请用 profile 配置。

### 2.3 Provider 配置（设置 → 插件 → 内容工作台）

| Provider | 用途 | 说明 |
|---|---|---|
| 图像（image） | 小红书图卡 / 公众号配图 | OpenAI 兼容 `/images/generations`，密钥走环境变量 |
| 配音（speech） | 视频旁白 | 未配置时只写待执行清单 |
| Remotion | 视频渲染 | 本地命令，仅记录 |
| 微信/小红书/抖音/视频号 | 平台发布 | 草稿写入需用户明确批准 |

密钥一律通过**环境变量名**引用（DSH 凭据服务），设置文件与页面不回显密钥值。

### 2.4 本地工具链

- **wewrite CLI**：`内容库/_工作台/wewrite-cli/.venv/Scripts/wewrite.exe`（评分/查重/排版）；未装时评分查重按钮会明确报错。
- **图像 Provider**：已配置时窗口内可直接生成图卡/配图；未配置时生成入口报错，不伪造图片。

## 3. 界面：四个窗口 + 右侧对话

| 窗口 | 内容 | 主要操作 |
|---|---|---|
| **顶部栏** | ⚙ 设置与画像 + 🚀 发布 | 画像表单（定位/读者/语气/方向/筛选标准）；Provider 状态；当前主题的平台就绪徽章与发布待执行清单（PENDING.md） |
| **总览与选题库** | 统计 + 三个标签页 | 「主题」：搜索/列表或看板视图/四闸门状态/新建主题；「选题库」：添加候选（标题+主张+来源）、挑选、批量转正/单条转正；「待办」：按闸门列出每个主题的下一步 |
| **内容编辑与修改** | 六个标签页 | 「公众号/小红书/视频」：正文编辑器 + 实时预览 + **自动保存** + 评分/查重；「审批与阶段」：四闸门批准 + 运行当前阶段 + 产物链；「发布」：生成/重新生成发布包、批准发布包；「资料」：Brief 选题卡编辑 |
| **配图及视频预览** | 三个标签页 | 「公众号配图」：生成配图 + 缩略图预览 + 微信排版预览 iframe；「小红书图卡」：生成图卡 + 缩略图；「视频预览」：成片播放器 + 场景/字幕内容查看 + 待执行清单 |
| **右侧对话窗** | worktable 原生 | 与 Agent 对话推进创作；Agent 按工作流处理当前主题 |

窗口间联动：点总览里的主题 → 编辑/预览窗口自动跟随；内容变更经 revision 广播自动刷新。

## 4. 创作流程（核心）

### 4.1 总览

```
素材库（飞书表格 / OrbitOS 知识库 / 本地文件）
   │  批量提取候选选题 → _工作台/candidates.yaml
   ▼
候选选题池（用户挑选）
   │  每条转正为独立主题（自动建主题文件夹）
   ▼
主题 → 四级人工审批闸门：
  brief_sources → approved_article → platform_variants → publish_package
   │
   ▼
发布（只停在人工确认前）→ 复盘沉淀（回写候选池）
```

### 4.2 阶段一：brief_sources（选题卡 + 来源）

1. **情报先行**：选题前先做平台情报——搜热点、挖爆款、看评论、拆竞品（web 搜索 + 素材库）；真实数据优先，拿不到就标注「未经数据验证」，**不编造互动量级**。
2. 有选题 → 新建主题 → 填 `brief.md` 选题卡（目标读者 / 核心问题 / 边界 / 待验证问题 / 来源）。
3. 没选题 → 在「选题库」添加候选 → 挑选 → 转正为主题。
4. 每个外部事实写入 `claims.yaml` 并关联 `sources/`；**没有来源的事实不能写成确定结论**。
5. 人工批准 `brief_sources` 闸门。

### 4.3 阶段二：approved_article（公众号长文）

1. **先诊断素材形态，再选六种写法之一**：访谈（有经历没结构）/ 大纲（有观点没展开）/ 续写（写一半卡住）/ 整合（一堆零散材料）/ 破题（主题定角度没定）/ 重写（成稿不满意）。
2. 按**公众号五约束**成稿：开头几句能独立成立；手机屏单段 ≤90 字；超 2000 字分小节；读者是订阅者不重复自我介绍；结尾只给一个动作。
3. 过 **AI 腔黑名单**（本质上/说白了、「不是 X 而是 Y」≤1 次、三段排比结尾等）与**成稿质检**（有没有「我」≥3 处、例子是否真实、有没有边界）。
4. 可在编辑器点「wewrite 评分」查质量分；修改后人工批准 `approved_article`。

### 4.4 阶段三：platform_variants（小红书 + 视频）

**小红书 `xhs/post.md`**：
- 开头 3 行是生死线；段落 1–3 行；第一人称；emoji 当分隔符。
- 按 **7 种笔记类型**（种草测评/干货教程/个人故事/合集清单/避雷拔草/好物分享/经验复盘）写。
- 标题按 **15 法**出 3–5 个候选并评分（搜索词覆盖/人群指向性/收藏动机）；红线：没真实做过不写「亲测/实测/坚持了 X 个月」。
- **三层标签**：大词引流 1–2 / 中词精准 3–4（涨粉主力）/ 小词卡位 3–5。
- 功效词与绝对化表述动笔就改（合规优先于爆款）。
- 图卡：在预览窗口（或编辑页小红书标签）输入画面提示词生成，Provider 未配置时写 PENDING 待执行清单。

**视频 `video/script.md`**：
- 口播**先能念再精确**：拆长句、去书面连接词、打破排比；判断标准 = 读出声。
- 分镜**精确到秒**：script.md 表格（时间/口播/画面/呈现/转场），供下游 scenes/captions 直接取用。
- 动手前定平台与比例（竖屏 3:4 / 横屏 16:9）。
- 「生成场景与字幕」由 Agent 派生 `scenes.json`/`captions.json`；成片需 Remotion Provider。

可与长文做**相似度查重**（内容级真改：只变表达不变主张）。修改后人工批准 `platform_variants`。

### 4.5 阶段四：publish_package（发布包）

1. 「发布」页检查平台就绪（公众号/小红书/抖音视频号素材是否齐全）。
2. 生成发布包 → `publish/package.json`（只描述可执行动作与素材，不代表已发布）。
3. wewrite gallery 生成 `publish/preview.html` 微信排版预览（预览窗口查看）。
4. 人工批准 `publish_package`。**不自动点击任何平台的最终发布按钮；平台草稿写入必须在用户明确批准后进行。**

### 4.6 复盘沉淀（发布后，非强制闸门）

- **六层漏斗归因**：曝光 → 点击 → 完读 → 互动 → 涨粉 → 转化；先定位卡在哪层再改（曝光低查标签定位、CTR 低改标题封面、互动低改正文）。
- **账号八维体检**：定位/选题/标题/正文/封面/标签/发布节奏/数据复盘。
- 可复用标题公式、封面模板、选题公式**回写素材库与候选池**，形成下一轮输入。

## 5. 主题目录契约（文件即真相）

```
contentRoot/
├── _工作台/
│   ├── candidates.yaml          # 候选选题池（status: pending|selected|converted）
│   └── creator-settings.json    # 工作台本地设置（不随仓库分发）
└── 2026-08/
    └── 2026-08-25_ai-workflow/          # 主题文件夹（计划日期_slug）
        ├── project.yaml                 # 元数据：id/title/slug/plannedAt/stage/targets
        ├── brief.md                     # 选题卡（顶部结构化字段 + 自由正文）
        ├── claims.yaml                  # 主张清单（fact 必须有来源）
        ├── sources/                     # 来源文件
        ├── wechat/article.md            # 公众号长文（表达锚点）
        ├── xhs/post.md + xhs/cards/     # 小红书文案 + 图卡（含 PENDING.md）
        ├── video/script.md              # 视频脚本（MM:SS 文本行）
        ├── video/scenes.json            # 场景（由 script 派生）
        ├── video/captions.json          # 字幕（由 script 派生）
        ├── video/final.mp4              # 成片（Remotion 渲染）
        ├── publish/package.json         # 发布包（审批后生成）
        ├── publish/preview.html         # 微信排版预览
        └── approvals.json               # 四级闸门审批记录
```

## 7. 纪律与边界

1. **四级闸门是硬约束**：批准是用户的人工动作，Agent 不代批、不跳过；卡点路由只在当前阶段内选打法，不越过闸门顺序。
2. **不编造**：无来源的事实不写进确定结论；无真实体验不写「我用了三个月」；无数据源不报互动量级（标注「未经数据验证」）。
3. **Provider 不可用 → PENDING**：图卡/配音/成片只写待执行清单，不伪造 PNG/音频/MP4 已生成。
4. **合规优先于爆款**：功效词、绝对化、医疗表述动笔就拦。
5. **只做参谋不做批量**：不自动发布、不刷互动、不做虚假人设。
6. **文件即真相**：正文用文件工具读写；工作台工具只做文件做不到的事（审批/阶段/候选池状态）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 窗口空白（显示窗格选择器） | F5 刷新 worktable；若布局窗格不足，在布局编辑器应用预设 **tb3**（顶栏+三列+右侧对话）后 F5；插件改版后若仍不重挂，改动 `widget-result.json` 原文（如 rev 字段）强制重挂 |
| 图卡/配图生成失败 | 检查图像 Provider 是否 configured（顶部栏有状态）；密钥经环境变量/DSH 凭据提供 |
| wewrite 评分/查重报错 | 检查 `内容库/_工作台/wewrite-cli/.venv/Scripts/wewrite.exe` 是否存在，或设 `ORIOS_WEWRITE_CLI` |
| 宿主改动不生效 | 重启 harness（按 3080 端口查 PID → Stop-Process → Start-Process dsh web）；客户端改动 F5（必要时 Ctrl+F5） |
| 找不到主题文件夹 | 主题位于 `contentRoot/YYYY-MM/YYYY-MM-DD_slug/`，如 `F:/Ori-OS/内容创作/2026-08/2026-08-23_示例-ai-工作流如何持续产出/` |

## 10. 协同闭环与按需聚焦（v0.3.0+）

创作是「人 × Agent」协作：**人 = 挑选 / 批准 / 录数据 / 微调；Agent = 调研 / 生成 / 分析 / 复盘**。三层功能已进界面：

| 入口 | 位置 | 闭环 |
|---|---|---|
| 情报台 | 总览窗口标签页 | 输入关键词 → 「发起赛道调研」→ Agent 产出 `_工作台/情报/YYYY-MM-DD_赛道.md` → 列表出现 → 「转选题」→ 候选池 +1 |
| 打法面板 | 编辑窗口各编辑器（折叠卡） | 公众号选六写法 / 小红书选 7 类型、生成标题候选（`xhs/titles.md`）/ 视频定比例写秒级分镜 → 按钮发任务给 Agent |
| 复盘台 | 总览窗口标签页 | 选主题 → 录六层漏斗数据 → 保存 `publish/review.md` → 「生成复盘」→ 归因+八维体检 → 「回写候选池」→ 池 +1 |
| 流水线导航 | 顶部栏 | 情报→选题→Brief→长文→变体→发布→复盘 七格状态，点击跳转到对应窗口/标签 |
| 按需聚焦 | 每个窗口「⛶ 聚焦」按钮 | 一键放大本窗（~70%），再点恢复均分；写长文时聚焦编辑窗，看报告时聚焦情报窗 |

- 按钮发任务走**对话桥**（同源 iframe → 绑定会话）；无绑定会话时自动复制提示词兜底。
- Agent 完成任务落盘 → revision 广播 → 对应窗口自动刷新，不用翻对话找结果。
- 报告路径约定（Agent 遵守）：情报 `_工作台/情报/`、标题 `xhs/titles.md`、复盘 `publish/review.md`。
