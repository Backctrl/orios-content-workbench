# creator-buddy 创作工作流融合标准

> 来源：github.com/SpaceZephyr/creator-buddy（MIT）——公众号 / 小红书 / 视频三平台全栈创作 Skill 工具箱。
> 完整子技能已 vendor 到本仓库 `vendor/creator-buddy/`（离线参考，见 vendor/README.md）。
> 本文件把它「**情报先行 → 卡点路由 → 平台打法 → 复盘沉淀**」的方法论映射进 OriOS 内容工作台的四级闸门流水线。
> 需要完整打法时，直接读 `vendor/creator-buddy/` 对应子技能的 `SKILL.md`（gzh-Skills/、xhs-Skills/、video-Skills/）。

## 一、总原则

1. **情报先行**：选题之前先做平台情报——搜热点、挖爆款、看评论、拆竞品。真实数据优先；拿不到数据就标注「未经数据验证」，**禁止编造互动量级**。
2. **卡点路由**：先判断用户卡在哪一环（定位 / 选题 / 写作 / 标题 / 封面 / 复盘），再选对应打法，不要为了走完流程硬插步骤。没定位就优化标题是无效功。
3. **平台专属**：每个平台有独立文体与红线，不要用公众号的直觉写小红书、用写文章的方式写口播。
4. **复盘沉淀**：发布后做数据归因与账号体检，把可复用结论回写素材库 / 候选池，成为下一轮选题的输入。
5. **纪律**：不编造（无真实体验不写「我用了三个月」）；合规优先于爆款（功效词 / 绝对化 / 医疗表述动笔就拦）；只做参谋不做批量（不自动发布、不刷互动、不做虚假人设）。

## 三、平台打法速查

### 公众号（approved_article）

- **六种写法路由**（先问「你手上有什么」，再选路）：
  1. 访谈式——有经历没结构（一次只问一个问题，追问往具体走，保留作者原话）；
  2. 大纲式——有观点没展开（先落带**字数配额**的大纲再扩写，必须含「反面/边界」一节）；
  3. 续写式——写一半卡住（先诊断卡点：没大纲补大纲 / 缺材料找案例 / 选题立不住就换角度，别硬撑）；
  4. 素材整合式——一堆零散材料（逐条压成一句 → 找共同主线 → 舍得删）；
  5. 破题式——主题定但角度没定（一次给 5–8 个角度，挑「只有你能写」的：反直觉/切身/对比/溯源/代价/人群/预测）；
  6. 重写式——成稿不满意（先输出病灶清单再定点手术，不整体润色）。
- **五约束**：开头几句能独立成立（摘要会原样截取）；手机屏单段 ≤90 字（约 4 行）；超 2000 字分小节且标题可扫读；读者是订阅者不重复自我介绍；结尾只给**一个**明确动作。
- **三种骨架选一种**：总分总 / 时间线 / 问题链。
- **AI 腔黑名单**：「本质上 / 说白了」「不是 X 而是 Y」（一篇 ≤1 次）、三段排比结尾、每段以「而/然而」开头。自问自答本身是好节奏，后面必须跟**具体**回答。
- **成稿质检**：有没有「我」（≥3 处作者独有判断）、例子是否真实、有没有边界、段落长度、开头独立、单一结尾、AI 腔。

### 小红书（platform_variants）

- **文体**：开头 3 行是生死线（折叠线）；段落 1–3 行；第一人称像跟朋友说话；emoji 当分隔符和节奏器。
- **7 种笔记类型**：种草测评 / 干货教程 / 个人故事 / 合集清单 / 避雷拔草 / 好物分享 / 经验复盘。
- **标题 15 法**（择 3–5 个出矩阵，按搜索词覆盖 / 人群指向性 / 收藏动机评分）：人群标签前置 / 搜索词卡位 / 数字清单+收藏指令 / 避雷劝退 / 后悔体 / 情绪惊叹 / 亲测对比 / 保姆级教程 / 反常识纠错 / 悬念缺口 / 场景具体化 / 平替省钱 / 时间承诺 / 求助互动 / 节点热点绑定。红线：**没真实做过不写「亲测 / 实测 / 坚持了 X 个月」**。
- **标签三层**：大词引流 1–2（博曝光）/ 中词精准 3–4（涨粉主力）/ 小词卡位 3–5（长尾）。
- **合规**：高危词（功效 / 绝对化 / 医疗）动笔就改，不等发布前体检；小红书违规常是限流而非删帖，最难自查。

### 视频（platform_variants → publish）

- **口播先能念再精确**：拆长句、去书面连接词（首先其次→然后你看）、打破排比、念不出的标点改口语；判断标准 = **读出声**。
- **分镜精确到秒**：`script.md` 表格（时间 / 口播 / 画面 / 呈现 / 转场），每行标注字幕文本、动画点、B-roll 需求供下游取用；不接受「想做 3 分钟视频」这种模糊描述。
- **落盘交接**：每步产出落盘（00_参考 → 01_选题 → 02_脚本 → 03_剪辑 → 04_broll → 05_字幕 → 06_封面），不留在对话里。
- **平台先行**：动手前定平台与比例（竖屏 3:4 / 横屏 16:9），避免返工。

## 四、复盘沉淀（publish 之后）

- **笔记复盘六层漏斗归因**：曝光 → 点击 → 完读 → 互动 → 涨粉 → 转化；**先定位卡在哪层再改**，顺序不能反（曝光低查标签定位，CTR 低改标题封面，互动低改正文）。
- **账号体检八维**：定位、选题、标题、正文、封面、标签、发布节奏、数据复盘。单篇问题走复盘，账号整体问题走体检。
- **结论回写**：可复用标题公式 / 封面模板 / 选题公式追加进素材库与候选池，形成下一轮输入。
